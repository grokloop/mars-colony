# Mars Colony

A public, walkable first-settlement on Mars. Not a game. No scores, quests, or win state. It is a place you walk.

Inspired by the Elon Musk / SpaceX civilize-Mars spine: Starship as the truck, a first base, solar power, ice / ISRU, habs, greenhouses, then a city. Day one is an early-but-alive outpost.

This is a living world. The settlement grows as people send PRs.

## How to start

Install dependencies, then start the Vite dev server.

Package scripts: dev -> vite, build -> vite build, preview -> vite preview.
Install with the node package manager, then run the dev script.


Open http://localhost:5173 after the dev server starts.

- Walk: /  (click, WASD, mouse look, Shift run, Space jump)
- Spectator: /preview.html  (cinematic camera, no controls)

No backend. No accounts. No analytics.

## Controls

- Click: start walking
- Mouse: look
- WASD: walk
- Shift: run
- Space: jump
- Esc: release pointer

Spawn is on the landing pad berm, looking at the Starship.

## Day-one landmarks

- Starship on landing legs (stainless, flaps, nose, heat-shield tiles, Raptor bells) plus cargo crates
- Landing pad and berm
- Solar farm east of the pad
- ISRU / propellant plant west, tanks labeled CH4 and O2
- Hab cluster and greenhouse north along the road
- Two rovers
- Workshop hangar
- Comms tower
- Ice-mining rig with a water-ice pile
- Paths connecting pad, plant, habs, and mine

## Stack

Vite + vanilla JavaScript + Three.js. No extra runtime dependencies.
